# minga-reels

**Одиннадцать навыков Claude для Instagram Reels и YouTube Shorts на русском и английском: персонажи и ИИ-герои, хуки с оценкой настоящим инструментом, сценарии с таймингом, подписи с проверкой по лимитам площадок, исследование, чистка текста, планы, разбор статистики и ответы на комментарии.**

Часть экосистемы [Minga](https://github.com/dmminga1983/minga). Один набор на обе площадки. В его основе файлы персонажей, поэтому один человек может вести несколько аккаунтов или тестировать нескольких ИИ-героев, и их голоса не смешиваются. Бесплатно, MIT, без API-ключей, ничего подключать не нужно. **За вас ничего не публикуется:** каждый навык заканчивается готовым блоком для копирования и вопросом «публикуем или правим?».

## Одиннадцать навыков

| команда | что делает |
| --- | --- |
| `/reels-persona` | Файл персонажа, который читают все навыки: кому он говорит, как звучит, что ему можно утверждать. Живой автор или ИИ-персонаж. |
| `/reels-hook` | Варианты хука по [26 формулам](skills/reels-hook/hooks.json) с оценкой `hookscore.py`: самое слабое место и как его исправить. Настраивается на ваших собственных роликах. |
| `/reels-script` | Из одной идеи сценарий: устный текст, отдельная дорожка текста на экране, раскадровка по битам с таймингом от `beats.py`. Карусели тоже. |
| `/reels-caption` | Подпись для Instagram или заголовок и описание для Shorts с проверкой `caption.py`: 125 видимых символов, 5 хештегов, один призыв, пометка ИИ. |
| `/reels-viral` | Что сейчас работает в нише, по кратности просмотров к медиане своего же аккаунта, с названием формулы. |
| `/reels-clean` | Убирает невидимые символы, длинные тире и пустые вводные, отмечает штампы и выпрашивание лайков, оценивает текст пятью локальными проверками. |
| `/reels-plan` | Неделя для одного персонажа или честный тест ниш для нескольких: одинаковое число роликов, те же дни и площадки, правило выбора решено заранее. |
| `/reels-audit` | Ваши собственные цифры: кратность к медиане, удержание на 3-й секунде, пересылки и подписки на 1000 охвата, сравнение по персонажам или площадкам. |
| `/reels-reply` | Сортировка комментариев под вашими роликами и комментарии к чужим постам голосом персонажа. |
| `/reels-repurpose` | Одно длинное видео, подкаст или документ превращается в самостоятельные короткие ролики, по возможности из ваших же кадров. |
| `/reels-character` | Для ИИ-персонажей: «библия» персонажа, каркас промпта, кадр на каждый бит, правила маркировки. |

## Установка

**Claude Code**, как плагин:

```
/plugin marketplace add dmminga1983/minga-reels
/plugin install minga-reels@minga-reels
```

Или скопируйте папки, чтобы команды назывались просто `/reels-hook` и так далее:

```bash
git clone https://github.com/dmminga1983/minga-reels.git
cp -r minga-reels/skills/reels-* ~/.claude/skills/
```

**claude.ai**: заархивируйте папку одного навыка и загрузите её в Настройки, Возможности, Навыки. Сама методика работает и без Claude Code, а инструментам нужна среда, где запускается Python.

Инструментам нужен Python 3.8 или новее, больше ничего.

Потом создайте первого персонажа: `/reels-persona`, или пришлите Claude три своих ролика со словами «напиши персонажа по этим». Файлы хранятся в `~/.claude/minga-reels/`.

## Инструменты

Чистый Python без зависимостей, без сети, никуда ничего не загружается. Язык, русский или английский, определяется по каждому тексту отдельно.

```bash
python3 skills/reels-hook/hookscore.py hooks.txt               # оценка хука по шести свойствам
python3 skills/reels-hook/calibrate.py corpus.tsv              # работает ли оценка в вашей нише?
python3 skills/reels-script/beats.py script.txt --target 30    # раскадровка с таймингом
python3 skills/reels-caption/caption.py caption.txt --ai       # проверка подписи
python3 skills/reels-caption/caption.py --platform shorts --title "..." desc.txt
python3 skills/reels-clean/clean.py draft.txt -o clean.txt --report
python3 skills/reels-clean/detect.py draft.txt clean.txt       # пять проверок, до и после
python3 skills/reels-viral/swipe.py captured.tsv               # выбросы по кратности к своей медиане
python3 skills/reels-audit/audit.py posts.csv --by persona     # что сработало, какой персонаж выиграл
```

**Время речи считается по слогам**: в русском слове больше слогов, и темп «слов в минуту» из английских руководств завышает, сколько влезает в три секунды. **Числа словами тоже считаются конкретикой**: «сорок тысяч» так же конкретно, как «40 000». **Классификатор узнаёт каждый из 26 своих примеров на обоих языках**, это проверяет тест.

```bash
python3 -m unittest discover -s tests -v
```

## Важные оговорки

- **Навыки не публикуют, не комментируют, не ставят лайки, не подписываются и не пишут в личку.** Автоматизация этого через браузер или сторонние сервисы нарушает правила Instagram, и аккаунты за это ограничивают. Единственное исключение, о котором говорят навыки: автоответы по ключевому слову через собственные инструменты Instagram или одобренного партнёра, и только после того, как человек сам написал комментарий.
- **`hookscore.py` это эвристика.** Он надёжно ловит слабые хуки: приветствия, вступления, эмоции вместо фактов, больше трёх секунд на произнесение. Выбрать победителя из двух приличных хуков он не может, это решают ваше лицо, монтаж, звук и сама площадка. `calibrate.py` измеряет, насколько оценка работает на ваших собственных роликах, по каждому свойству отдельно, и показывает, какие свойства в вашей нише ничего не значат.
- **Пять проверок текста это локальные эвристики**, а не GPTZero или другой детектор. Честно пообещать «не определится как ИИ» не может никто.
- **Ничего не выдумывается.** Никаких цифр, клиентов, результатов и опыта от имени персонажа. Если цифры нет, в тексте будет `{{your number}}` и пометка.
- **ИИ-персонажи маркируются.** Пометка ИИ в Instagram и настройка «изменённый или синтетический контент» в YouTube на каждом ролике, никакой внешности и голоса реальных людей, никаких выдуманных профессиональных регалий.
- **Цифры площадок меняются.** Лимиты в `caption.py` проверены в октябре 2026 года (ограничение в 5 хештегов в Instagram действует с декабря 2025). Если площадка говорит иначе, права площадка: поправьте таблицу `LIMITS`.
- **Исследование читает, а не парсит.** Публичные данные Shorts через `yt-dlp` на вашем компьютере, Instagram в вашем браузере, в человеческом темпе и при вас.
